# app

The SwiftUI menu bar app: menu bar item, popover, history window, Dynamic Island panel and settings. It links the Rust core from `core/` as a static library.

Created in milestone M0 ([`docs/plan.md`](../docs/plan.md#m0-repository-foundation)). The design it implements is in [`docs/design.md`](../docs/design.md) and [`prototypes/ui-spike`](../prototypes/ui-spike).
