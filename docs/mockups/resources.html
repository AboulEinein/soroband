4 · Menu bar readings

New reading tiles in Settings › Menu Bar, beside today's total and the live speeds, in each existing style. Each redraw costs about 18 ms of the main thread on a four-display Mac, so a reading that changes on every poll (CPU busy) is measured before it is offered, like the live speed.

6 · How each resource reads

Each resource's reading is set once, in a "Show" group in Settings › Resources. That one setting covers the popover's gauges, the menu bar reading and the past-minute chart, so the views can't disagree. The preview row draws the result live. History's per-app numbers (CPU time, average footprint, bytes read and written, Wh) are totals over a range, so they keep one form.
