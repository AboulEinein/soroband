Option C · Warm

Base: the expressive prototype. A hero card tinted with the network you are on, today in hourly beads, rounded numerals, warm cards. Network colors appear only where they mean a network.
1 · Menu bar item, every display mode

Glyph: the current network's kind (Wi‑Fi, Hotspot, Ethernet) as a template image, never colored in the menu bar, so a metered hotspot is visible at a glance. The abacus mark lives inside the app (All Networks in History). Text: .monospacedDigit() so the width never jitters; the item reserves its widest string per mode (NSStatusItem.length fixed per mode), so neighbors do not shift. No animation: values change on poll only. "↓ and ↑" stacks two lines at 9.5 pt like iStat Menus, built as a two-line NSAttributedString in the button.

2 · Popover, 360 pt
Apps tab, current network (Keyez!_5G)
Networks tab
Location not allowed: Wi‑Fi named by router

The hero card is tinted with the current network's color (.background(color.gradient.opacity(...)) plus a RadialGradient), so the popover says "you are on the blue network" before you read a word. The bead strip is today's 24 hours on this network (Chart { BarMark } with .chartXAxis(.hidden), or plain HStack of RoundedRectangle), the current hour ringed. On open, beads and bars grow once (.animation(.spring(duration: 0.5)) keyed on an onAppear flag); nothing animates after that, and live speed updates by text only. History moves from a borderless text button to a full-width card: label, this month's total and a 7-day spark, with ⌘Y. Settings and Quit become quiet square icon buttons.

3 · History window, 1100 × 800, Month · All Networks

Hierarchy: one headline row answers "how much, and where" (total with ↓/↑ ratio, then share by network as a big segmented bar with labels). The chart spans full width and calls out the busiest day and average in the plot, so the four stat tiles disappear. Below, Apps take the wide column (per-network split under each bar; the expanded row lists bytes per network), the heatmap sits beside it with a one-line plain-language insight. APIs: NavigationSplitView with List(selection:) sidebar, toolbar Picker(.segmented) + ControlGroup for ← Today →, Swift Charts BarMark(stacking: .standard) + .foregroundStyle(by: .value("Network", …)) + .chartForegroundStyleScale, RuleMark for average with .annotation, .chartXSelection for the hover day with a labelled breakdown, RectangleMark for the heatmap.
